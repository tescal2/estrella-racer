# Estrella Racer

Lightweight browser racing game for GitHub Pages with:
- Bilingual UI (English/Spanish)
- Personalized player names (Axel + Jade by default)
- Two modes: Race Mode + Loco Mode
- Star-heavy neon theme
- iPhone Safari-first controls and layout

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Push this folder to a repository named `estrella-racer`.
2. In repository settings, enable Pages from the default branch root.
3. Open `https://<username>.github.io/estrella-racer/`.

## Avatar photo drop folder
Drop a side-by-side reference image in:

`assets/reference/axel-jade/`

Privacy default: this folder is git-ignored (except `.gitkeep`), so child photos are not committed to GitHub.

Supported sample filenames in this MVP:
- `Axel-Jade.heic`
- `side-by-side.jpg`
- `side-by-side.png`
- `photo.jpg`
- `photo.png`

The image is shown in the garage panel as inspiration for stylized in-game avatars.
